# Красное море: открытый офлайн-определитель

Русскоязычный полевой определитель кораллов, рыб, моллюсков и ракообразных для района **Faraana Reef / Temple / Ras Katy / Ras Um Sid**. В исходных данных **98 видов и групп**. PDF собирается с **реальными фотографиями из Wikimedia Commons, встроенными прямо в документ**; открывать фото в интернете после сборки не требуется.

## Самый простой способ: без установки Python — GitHub Actions

1. Создайте репозиторий на GitHub и загрузите **всё содержимое** этого каталога (включая скрытую папку `.github`).
2. На вкладке **Actions** выберите **Build offline Red Sea photo guide** → **Run workflow**.
3. По завершении откройте выполненный запуск, скачайте артефакт **red-sea-offline-photo-guide**. Внутри — PDF, список авторов и лицензий, сводка отсутствующих снимков. PDF готов для телефона и не требует интернета.
4. При необходимости перезапустите задачу: уже загруженные изображения кэшируются, если репозиторий поддерживает кэш Actions.

> **Важно:** этот ZIP содержит открытые исходники, но **не содержит заранее скачанных фотографий**. При первом запуске сборщика нужен интернет — ровно для того, чтобы скачать фотографии и вшить их в PDF. Автосборка выполняется в GitHub Actions, а не на вашем телефоне.

## Локальная сборка (Linux/macOS/Windows)

Нужны Python 3.10+, интернет при первой загрузке, а также шрифт DejaVu Sans или Noto Sans с кириллицей.

```bash
python -m pip install -r requirements.txt
python src/build.py --photos 2
```

Готовый PDF будет в `output/Red_Sea_Field_Guide_OFFLINE_PHOTOS_RU.pdf`. Изображения остаются в `assets/`, а полная атрибуция — в `output/PHOTO_CREDITS.csv` и `data/manifest.json`. После первой загрузки новый PDF можно собрать **без сети**:

```bash
python src/build.py --offline
```

Для быстрой тестовой сборки: `python src/build.py --limit 4 --photos 1`.

## Почему некоторые фотографии могут отсутствовать

Скрипт берёт только изображения с разрешённой повторной публикацией: CC0, общественное достояние, CC BY или CC BY-SA. Он не подставляет картинку похожего вида, если на Commons не нашёл точного соответствия. Для родов и групп возможна иллюстрация представителя рода, а не всех видов. Непроверенные, неподходящие или недоступные файлы пропускаются — так лучше, чем ложное определение.

Некоторые виды (например манта) редки у берегов Шарм-эль-Шейха: **включение в справочник не означает, что конкретное животное обитает именно у пляжа Faraana**.

## Где менять текст и изображения

- `data/species.json` — названия, признаки, места наблюдения и отметки «ТЫ ВИДЕЛ».
- `data/curated.json` — вручную проверенные *названия файлов на Commons* (сейчас включены фотографии из Ras Katy и Красного моря).
- `src/build.py` — поиск по Commons, фильтрация лицензий, скачивание, уменьшение и PDF-верстка.
- `assets/` — сохранённые после запуска JPEG (не включены в исходный репозиторий).
- `data/manifest.json` — список фактически встроенных снимков и данные об их лицензировании (создаётся после загрузки).

## Лицензии и атрибуция

- Код: **MIT** (`LICENSE`).
- Авторские тексты, подготовленные для проекта: **Creative Commons Attribution–ShareAlike 4.0** (`TEXT_LICENSE.md`).
- **Фотографии не переоформляются под MIT или CC BY-SA всего проекта.** Каждая фотография сохраняет свою отдельную лицензию, автора и ссылку на страницу Commons. Сборщик встраивает соответствующие сведения в PDF и создаёт `PHOTO_CREDITS.csv`.
- Для сокращения размера в PDF изображения уменьшаются до ~1100 пикселей, без намеренных художественных изменений. Это отмечается в атрибуции.
- Проверьте требования конкретной лицензии перед публикацией изменённых изображений или продажей печатного издания.

## Ограничения

Это практический визуальный определитель, а не научная фаунистическая инвентаризация. На видовом уровне идентификация кораллов и некоторых ракообразных может требовать микроскопии или дополнительных признаков. Подводные условия, течения и видимость могут быть небезопасны. Ничего не трогайте, особенно крылаток, скорпен, конусов и скатов.

**Развитие проекта:** PR с проверенными фотографиями, коррекциями таксономии и картой наблюдений приветствуются. Пожалуйста, добавляйте атрибуцию, дату, место съёмки и ссылку на первоисточник.
